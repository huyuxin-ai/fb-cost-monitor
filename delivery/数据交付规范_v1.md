## 2. 交付物与节奏

- **文件**：`原材料价格采集模板_v1.xlsx`，文件名改为 `采集_成员X_YYYYMMDD.xlsx`
- **频率**：每周1次，**每周五 17:00 前**发送给数据库负责人
- **方式**：共享文件夹 / 邮件 / 飞书（三选一，团队统一）
- 数据源恢复API或采购到位后，对应品种转自动采集，成员工作量相应减少

## 3. 字段规范（与数据库 `fact_price_daily` 一一对应，违者退件）

| 字段 | 必填 | 规则 |
|---|---|---|
| 品种ID | ✅ | 使用模板预置ID，禁止改名/新建（新需求找DB负责人登记） |
| 数据日期 | ✅ | `YYYY-MM-DD`，取报价当日 |
| 价格 | ✅ | 纯数字，不带单位、千分位、约等号 |
| 单位 | ✅ | 用模板预置单位（元/吨、元/kg、美元/吨、元/公斤） |
| 口径 | ✅ | 只能填「国产」或「进口」，与模板默认一致 |
| 数据源名称+链接 | ✅ | 无来源不收；采购库数据标注库名（如"博亚和讯-维生素频道"） |
| 采集人/采集时间 | ✅ | 责任留痕 |
| 备注 | 条件必填 | 周变动>±5% 必须写原因；无报价写「本周无报价」，**禁止填0** |

## 4. 口径字典（与数据库 `dim_caliber` 完全一致）

1. **价格口径**：数据源原始口径（现货评估价/成交价/挂牌价），含税；进口为到岸口径、国产为出厂口径，**禁止自行换算或跨源拼接**
2. **周口径**：ISO-8601 自然周；周聚合自动取该周最后一条报价
3. **美元品种**：原样以"美元/吨"登记（鳀鱼、沙丁鱼、鱼油），汇率由数据库按月均值统一换算
4. **同品种多口径**：国产/进口分行登记（模板已预置，如奶油分两行）
5. **历史补录**：补录历史数据时，数据日期填实际报价日，备注写「补录」

## 5. 验收流程（DB负责人在收到后1个工作日内完成）

1. 运行 `validate_ingest.py 采集_成员X_YYYYMMDD.xlsx` 自动校验：
   - 字段完整性 / 日期格式 / 价格为数值 / 口径合法 / 单位匹配 / 品种ID在库
   - 周变动>±20% 触发人工复核提醒（不拒收，需备注支撑）
2. 校验通过 → 入库 → 回复「已入库」；不通过 → 退件并附错误清单
3. 所有问题登记 `test_log`（谁的数据、什么问题、怎么处理的）

## 6. 数据责任

- 采集人对**来源真实性**负责：价格必须可溯源（链接/截图/采购库条目号）
- DB负责人对**入库与口径一致性**负责：不改数、不补数，只验收与登记
- 争议数据：先入库并标记 `need_review`，由管理者（研究员）仲裁

## 7. 采购中品种（到位后转自动）

生鲜乳（农业农村部/奶业协会）、乳清蛋白与奶油（GDT）、维生素全族（博亚和讯）、PET/叶黄素/辣椒素（百川盈孚）、坚果（卓创）、鱼油原料（IFFO）——采购进度见网站「数据源与口径」页。
